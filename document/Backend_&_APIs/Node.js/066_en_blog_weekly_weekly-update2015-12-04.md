# Weekly Update - Dec 4th, 2015

Minwoo Jung

### [Node.js News — December 4th](https://nodejs.org#nodejs-news--december-4th)

Node v5.1.1 (Current), v4.2.3 "Argon" (LTS), v0.12.9 (LTS) and v0.10.41 (Maintenance) are released

### [December Security Release Summary](https://nodejs.org#december-security-release-summary)

- This is an important security release. Please update your Node.js installation.
- We have released Node.js [v0.10.41 (Maintenance)](https://nodejs.org/en/blog/release/v0.10.41/), [v0.12.9 (LTS)](https://nodejs.org/en/blog/release/v0.12.9/), [v4.2.3 "Argon" (LTS)](https://nodejs.org/en/blog/release/v4.2.3/) and [v5.1.1 (Current)](https://nodejs.org/en/blog/release/v5.1.1/) with fixes for the announced vulnerabilities and updates to OpenSSL.
- All Node.js users should consult our December Security Release Summary for details on patched vulnerabilities. (/(/(/(/ See /blog/vulnerability/december-2015-security-releases/ for more information.

- [Automatic cat feeder powered by Node.js](https://github.com/rachelnicole/robokitty), "Is a DIY cat (or dog, or human) feeder controlled over the web."
