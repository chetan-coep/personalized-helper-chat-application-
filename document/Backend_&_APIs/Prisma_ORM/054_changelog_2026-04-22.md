# Set the query plan cache size in Prisma ORM

Prisma ORM adds a parameter that sets the query plan cache size. It also fixes JSON equality evaluation and stops the Cloudflare D1 adapter from attempting unsupported savepoint operations.

## Prisma ORM

Prisma ORM adds query plan cache tuning and fixes JSON equality and Cloudflare D1 correctness issues.

- **New** · Prisma ORM now accepts a parameter that sets the size of the query plan cache. ([prisma/prisma#29503](https://github.com/prisma/orm/pull/29503))
- **Fixed** · Prisma ORM case-insensitive equality on JSON values returns the correct result. ([prisma/prisma-engines#5806](https://github.com/prisma/prisma-engines/pull/5806))
- **Fixed** · Prisma ORM equality checks on JSON list values behave consistently. ([prisma/prisma-engines#5804](https://github.com/prisma/prisma-engines/pull/5804))
- **Fixed** · The Prisma ORM D1 adapter no longer attempts savepoint operations, which Cloudflare D1 does not support. ([prisma/prisma#29499](https://github.com/prisma/orm/pull/29499))
