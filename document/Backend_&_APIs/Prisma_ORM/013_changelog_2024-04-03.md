# Prisma ORM v5.12.0: Cloudflare D1 in Preview

Exciting news! **5.12.0** release brings Preview support for [Cloudflare D1](https://developers.cloudflare.com/d1/) with Prisma ORM 🥳

D1 is Cloudflare's native serverless database and was initially launched in 2022. It's based on SQLite and can be used when deploying applications with Cloudflare. Cloudflare has recently [announced](https://blog.cloudflare.com/making-full-stack-easier-d1-ga-hyperdrive-queues) launching D1 in GA and we couldn't be happier to be adding support and working with them on this new milestone.

Read more in our latest [blog post](https://www.prisma.io/blog/build-applications-at-the-edge-with-prisma-orm-and-cloudflare-d1-preview).

## Implementing `createMany()` for SQLite

Bringing support for `createMany()` in SQLite has been a [long-awaited and highly requested feature](https://github.com/prisma/orm/issues/10710) ⭐

`createMany()` is a method on Prisma Client, released back in version [2.16.0](https://github.com/prisma/orm/releases/tag/2.16.0), that lets you insert multiple records into your database at once. This can be really useful when seeding your database or inserting bulk data.

Read more in our latest [release notes](https://github.com/prisma/orm/releases/tag/5.12.0).
