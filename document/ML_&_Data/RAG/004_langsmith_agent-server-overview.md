# Agent Server - Docs by LangChain

Source: https://docs.langchain.com/langsmith/agent-server-overview

---

Configure and build applications on the

[Agent Server](https://docs.langchain.com/langsmith/agent-server)runtime. Once deployed, agents work with three primitives:

[**assistants**](https://docs.langchain.com/langsmith/assistants)for configuration,

[**threads**](https://docs.langchain.com/langsmith/use-threads)for state, and

[**runs**](https://docs.langchain.com/langsmith/runs)for workloads. The pages in this tab cover the capabilities Agent Server provides, how to

[structure your application](https://docs.langchain.com/langsmith/application-structure), and how to

[secure](https://docs.langchain.com/langsmith/auth)and

[customize](https://docs.langchain.com/langsmith/custom-routes)the server.
