**Agent = Model + Harness.**LangChain provides

`create_agent`: a minimal, highly configurable harness. The harness is everything around the model loop: the prompt, the tools, and any middleware that shapes behavior. Start with the primitives and compose exactly what your use case needs. Supports [OpenAI, Anthropic, Google, and more](https://docs.langchain.com/oss/python/integrations/providers/overview).
