# Metaprogramming library (since C++11)

C++ provides metaprogramming facilities, such as type traits, compile-time rational arithmetic, and compile-time integer sequences.

The header [`<type_traits>`](https://en.cppreference.com/cpp/header/type_traits) provides [compile-time template-based interfaces to query the properties of types](https://en.cppreference.com/cpp/meta/type_traits).

The header [`<ratio>`](https://en.cppreference.com/cpp/header/ratio) provides [types and functions for manipulating and storing compile-time ratios](https://en.cppreference.com/cpp/numeric/ratio).

### [Compile-time reflection](https://en.cppreference.com/cpp/meta/reflection) (since C++26)

The header [`<meta>`](https://en.cppreference.com/cpp/header/meta) provides [facilities for static reflection and reflective metaprogramming](https://en.cppreference.com/cpp/meta/reflection).
