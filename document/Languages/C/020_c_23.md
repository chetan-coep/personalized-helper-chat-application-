# C23

From cppreference.com

**ISO/IEC 9899:2024**, a.k.a. **C23**, is the current revision of the C standard.

- [The latest publicly available WD of C23](https://open-std.org/JTC1/SC22/WG14/www/docs/n3998.pdf) (n3998, 2026-10-21).
- [The latest WD of C23](https://open-std.org/JTC1/SC22/WG14/www/docs/n3149.zip) (n3149, 2023-07-09, a password-protected zip archive, see [n3150](https://open-std.org/JTC1/SC22/WG14/www/docs/n3150.htm)).

C23 bumps the predefined macro \_\_STDC\_VERSION\_\_ to `202311L`.

## Obsolete features

### Removed features

- Old-style [function declarations](https://en.cppreference.com/c/language/function_declaration) and [function definitions](https://en.cppreference.com/c/language/function_definition)
- Representations for [signed integers](https://en.cppreference.com/c/language/arithmetic_types) other than two's complement
- Permission that `u`/`U`-prefixed [character constants](https://en.cppreference.com/c/language/character_constant) and [string literals](https://en.cppreference.com/c/language/string_literal) may be not UTF-16/32
- Mixed wide [string literal](https://en.cppreference.com/c/language/string_literal) concatenation
- Support for calling [`realloc()`](https://en.cppreference.com/c/memory/realloc) with zero size (the behavior becomes undefined)
- [`__alignof_is_defined`](https://en.cppreference.com/c/types) and [`__alignas_is_defined`](https://en.cppreference.com/c/types)
- [`static_assert`](https://en.cppreference.com/c/error/static_assert) is not provided as a macro defined in [`<assert.h>`](https://en.cppreference.com/c/header/assert) (becomes a keyword)
- [`thread_local`](https://en.cppreference.com/c/thread/thread_local) is not provided as a macro defined in [`<threads.h>`](https://en.cppreference.com/c/header/threads) (becomes a keyword)

### Deprecated features

- [`<stdnoreturn.h>`](https://en.cppreference.com/c/header/stdnoreturn)
- Old feature-test macros
- [`_Noreturn`](https://en.cppreference.com/c/language/_Noreturn) function specifier
- [`_Noreturn`](https://en.cppreference.com/c/language/attributes/noreturn) attribute token
- [asctime()](https://en.cppreference.com/c/chrono/asctime)
- [ctime()](https://en.cppreference.com/c/chrono/ctime)
- [`DECIMAL_DIG`](https://en.cppreference.com/c/types/limits) (use the appropriate type-specific macro ([`FLT_DECIMAL_DIG`](https://en.cppreference.com/c/types/limits#Limits_of_floating-point_types), etc) instead)
- Definition of following numeric limit macros in [`<math.h>`](https://en.cppreference.com/c/header/math) (they should be used via [`<float.h>`](https://en.cppreference.com/c/header/float))
- [`__bool_true_false_are_defined`](https://en.cppreference.com/c/types)

## New language features

- [Decimal floating-point types](https://en.cppreference.com/c/language/arithmetic_types) ([`_Decimal32`](https://en.cppreference.com/c/keyword/_Decimal32), [`_Decimal64`](https://en.cppreference.com/c/keyword/_Decimal64), and [`_Decimal128`](https://en.cppreference.com/c/keyword/_Decimal128))
- [Bit-precise integers](https://en.cppreference.com/c/language/arithmetic_types) ([`_BitInt`](https://en.cppreference.com/index.php?title=c/keyword/_BitInt&action=edit&redlink=1))
- [Binary integer constants](https://en.cppreference.com/c/language/integer_constant)
- [`u8` character constants](https://en.cppreference.com/c/language/character_constant)
- Type change of [`u8` string literals](https://en.cppreference.com/c/language/string_literal)
- Digit separator `'`
- Empty [initializer](https://en.cppreference.com/c/language/initialization) `={}`
- [Attributes](https://en.cppreference.com/c/language/attributes)
  - `[[`[deprecated](https://en.cppreference.com/c/language/attributes/deprecated)]]
  - `[[`[fallthrough](https://en.cppreference.com/c/language/attributes/fallthrough)]]
  - `[[`[maybe_unused](https://en.cppreference.com/c/language/attributes/maybe_unused)]]
  - `[[`[nodiscard](https://en.cppreference.com/c/language/attributes/nodiscard)]]
  - `[[`[noreturn](https://en.cppreference.com/c/language/attributes/noreturn)]]
  - `[[`[reproducible](https://en.cppreference.com/c/language/attributes/reproducible)]]
  - `[[`[unsequenced](https://en.cppreference.com/c/language/attributes/unsequenced)]]
- Unnamed parameters in [function definitions](https://en.cppreference.com/c/language/function_definition)
- Identical cvr-qualifications for [array types](https://en.cppreference.com/c/language/array) and their element types
- Single-argument [`_Static_assert`](https://en.cppreference.com/c/language/_Static_assert)
- [`static_assert`](https://en.cppreference.com/c/keyword/static_assert) becomes a keyword (may be a predefined macro for compatibility reasons)
- [`thread_local`](https://en.cppreference.com/c/keyword/thread_local) becomes a keyword (may be a predefined macro for compatibility reasons)
- [Labels](https://en.cppreference.com/c/language/goto) followed by declarations and **}**
- [`nullptr`](https://en.cppreference.com/c/keyword/nullptr) constant and the associated [`nullptr_t`](https://en.cppreference.com/c/types/nullptr_t) type
- [`true`](https://en.cppreference.com/c/keyword/true) and [`false`](https://en.cppreference.com/c/keyword/false) become keywords (may be predefined macros for compatibility reasons)
- New preprocessor directives
- Pragmas for rounding direction
  - `STDC` [`FENV_ROUND`](https://en.cppreference.com/c/preprocessor/impl)
  - `STDC` [`FENV_DEC_ROUND`](https://en.cppreference.com/c/preprocessor/impl)

### Feature test macros for optional features

- [`__STDC_IEC_60559_BFP__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates IEEE-754 binary floating-point arithmetic and required math functions are supported.
  - This macro supersedes [`__STDC_IEC_559__`](https://en.cppreference.com/c/preprocessor/replace).
- [`__STDC_IEC_60559_DFP__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates IEEE-754 decimal floating-point arithmetic and required math functions are supported.
- [`__STDC_IEC_60559_COMPLEX__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates IEEE-754 complex arithmetic and required math functions are supported.
  - This macro supersedes [`__STDC_IEC_559_COMPLEX__`](https://en.cppreference.com/c/preprocessor/replace).
