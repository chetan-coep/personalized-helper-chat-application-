**ISO/IEC 9899:1999**, a.k.a. **C99**, is a previous revision of the C standard.

## New language features

- Universal-character-names in [identifiers](https://en.cppreference.com/c/language/identifier)
- Increased [translation limits](https://en.cppreference.com/c/language/identifier#Translation_limits)
- `//` [comments](https://en.cppreference.com/c/comment)
- [`restrict`](https://en.cppreference.com/c/language/restrict) pointers
- Enhanced [arithmetic types](https://en.cppreference.com/c/language/arithmetic_types)
  - `_Bool`
  - `long long` and `unsigned long long`
  - Extended integer types
  - [`_Complex`](https://en.cppreference.com/c/keyword/_Complex) types (`float _Complex`, `double _Complex`, and `long double _Complex`)
  - [`_Imaginary`](https://en.cppreference.com/c/keyword/_Imaginary) types (`float _Imaginary`, `double _Imaginary`, and `long double _Imaginary`)
- Flexible array members
- [Variable-length array](https://en.cppreference.com/c/language/array#Variable-length_arrays) (VLA) types and variably-modified (VM) types
- Improvements of braced-init-list for [array](https://en.cppreference.com/c/language/array_initialization), [struct and union](https://en.cppreference.com/c/language/struct_initialization) types
  - Non-constant initializers
  - Designated initializers
- Idempotent cvr-qualifiers
- Trailing comma in [enumerator-list](https://en.cppreference.com/c/language/enum)
- Hexadecimal [floating constants](https://en.cppreference.com/c/language/floating_constant)
- [Compound literals](https://en.cppreference.com/c/language/compound_literal)
- Floating-point environment
- Requiring truncation for divisions of signed integer types
- Implicit `return 0;` in the [`main()` function](https://en.cppreference.com/c/language/main_function)
- Declarations and statements in mixed order
- init-statement in [`for`](https://en.cppreference.com/c/language/for) loops
- [`inline`](https://en.cppreference.com/c/language/inline) functions
- Predefined variable [`__func__`](https://en.cppreference.com/c/language/function_definition)
- Cvr-qualifiers and `static` in `[]` within function declarations
- [Variadic macros](https://en.cppreference.com/c/preprocessor/replace)
- [`_Pragma`](https://en.cppreference.com/c/preprocessor/impl) preprocessor operator
- Standard pragmas for floating-point evaluation
  - `STDC` [`FENV_ACCESS`](https://en.cppreference.com/c/preprocessor/impl)
  - `STDC` [`FP_CONTRACT`](https://en.cppreference.com/c/preprocessor/impl)
  - `STDC` [`CX_LIMITED_RANGE`](https://en.cppreference.com/c/preprocessor/impl)

### Feature test macros for optional features

- [`__STDC_IEC_559__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates IEEE-754 binary floating-point arithmetic and required math functions are supported.
- [`__STDC_IEC_559_COMPLEX__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates IEEE-754 complex arithmetic and required math functions are supported.
- [`__STDC_HOSTED__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates that the implementation is [hosted](https://en.cppreference.com/c/language/conformance).
- [`__STDC_ISO_10646__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates that Unicode is used by the wide literal encodings and expands to the latest supported revision.
- [`__STDC_MB_MIGHT_NEQ_WC__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates that there are some characters in the basic character set having different code unit values in [ordinary and wide literal encodings](https://en.cppreference.com/c/language/character_constant).

### Library features

- [Aliases for integer types](https://en.cppreference.com/c/types/integer)
  - Integer types with exact width (`int`*N*_t
and `uint`*N*_t
)
  - Fastest integer types with at least given width (`int_fast`*N*_t
and `uint_fast`*N*_t
)
  - Smallest integer types with at least given width (`int_least`*N*_t
and `uint_least`*N*_t
)
  - Integer types capable for cast between object pointers ([intptr\_t](https://en.cppreference.com/c/types/integer) and [uintptr\_t](https://en.cppreference.com/c/types/integer))
  - Integer types with maximum width ([intmax\_t](https://en.cppreference.com/c/types/integer) and [uintmax\_t](https://en.cppreference.com/c/types/integer))
- Operations on `long long` and [intmax\_t](https://en.cppreference.com/c/types/integer)
- [Floating-point environment access](https://en.cppreference.com/c/numeric/fenv)
- Extended floating-point math functions
  - New floating-point math functions
  - \-`f` and -`l` variants for existing and new floating-point math functions
  - [Math error handling](https://en.cppreference.com/c/numeric/math/math_errhandling)
- [Complex functions](https://en.cppreference.com/c/numeric/complex)
- [\_Exit()](https://en.cppreference.com/c/program/_Exit)
- Formatting support for `long long`, `unsigned long long`, [intmax\_t](https://en.cppreference.com/c/types/integer), and [uintmax\_t](https://en.cppreference.com/c/types/integer)
- [isblank()](https://en.cppreference.com/c/string/byte/isblank) and [iswblank()](https://en.cppreference.com/c/string/wide/iswblank)
- [snprintf()](https://en.cppreference.com/c/io/fprintf) and [vsnprintf()](https://en.cppreference.com/c/io/vfprintf)
- [vfscanf()](https://en.cppreference.com/c/io/vfscanf) and [vfwscanf()](https://en.cppreference.com/c/io/vfwscanf) function families
- Extensions for [`fscanf()`](https://en.cppreference.com/c/io/fscanf) and [`fprintf()`](https://en.cppreference.com/c/io/fprintf) function families
  - `ll` length modifier for `long long` and `unsigned long long`
  - `hh` length modifier for `signed char` and `unsigned char`
  - `l` length modifier for `double`
  - `z` length modifier for [size\_t](https://en.cppreference.com/c/types/size_t) and its signed version
  - `t` length modifier for [ptrdiff\_t](https://en.cppreference.com/c/types/ptrdiff_t) and its unsigned version
  - `j` length modifier for [intmax\_t](https://en.cppreference.com/c/types/integer) and [uintmax\_t](https://en.cppreference.com/c/types/integer)
  - `a` conversion specifier for floating-point types
- Numeric limit macros for `long long` and `unsigned long long`
- Numeric limit macros corresponding to existing and new aliases for integer types
- [Format string macros for integer types](https://en.cppreference.com/c/types/integer#Format_macro_constants)
- [`va_copy`](https://en.cppreference.com/c/variadic/va_copy)
- [Type-generic math macros](https://en.cppreference.com/c/numeric/tgmath)
- Floating-point comparison macros
- Floating-point classification macros
- Compatibility macros for `_Bool` ([`bool`](https://en.cppreference.com/c/types), [`true`](https://en.cppreference.com/c/types), and [`false`](https://en.cppreference.com/c/types))
