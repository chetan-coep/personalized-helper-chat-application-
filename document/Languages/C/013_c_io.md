# File input/output

The [`<stdio.h>`](https://en.cppreference.com/c/header/stdio) header provides generic file operation support and supplies functions with narrow character input/output capabilities.

The [`<wchar.h>`](https://en.cppreference.com/c/header/wchar) header supplies functions with wide character input/output capabilities.

I/O streams are denoted by objects of type [FILE](https://en.cppreference.com/c/io/FILE) that can only be accessed and manipulated through pointers of type `FILE*`. Each stream is associated with an external physical device (file, standard input stream, printer, serial port, etc).
