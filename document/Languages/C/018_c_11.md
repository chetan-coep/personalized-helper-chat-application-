### Feature test macros for optional features

- [`__STDC_ANALYZABLE__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates analyzability is supported.
- [`__STDC_LIB_EXT1__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates bounds checking functions are supported.
- [`__STDC_NO_ATOMICS__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates atomic objects and the atomic operation library are not supported.
- [`__STDC_NO_COMPLEX__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates complex types and the complex math functions are not supported.
  - These features were mandatory in C99.
- [`__STDC_NO_THREADS__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates thread local storage and the thread support library are not supported.
- [`__STDC_NO_VLA__`](https://en.cppreference.com/c/preprocessor/replace)
  - Indicates [variable length arrays and variably modified types](https://en.cppreference.com/c/language/array#Variable-length_arrays) are not supported.
  - These features were mandatory in C99.
