# SQL

Source: https://www.postgresql.org/download/snapshots

---

Beta and Release Candidate packages are built prior to the release of new major versions of PostgreSQL. They are not built continually.

Development snapshots are built from the latest source code and beta/rc versions that the developers are working on. These are 'bleeding edge' versions of PostgreSQL and should not be used in production systems as they have had little or no testing or quality control.

The latest development version of the documentation is also
[available online](https://www.postgresql.org/docs/devel/index.html).

Beta and Release Candidate tarballs are [made available
alongside](https://www.postgresql.org/ftp/source/) the release tarballs during the final phases of the development
cycle of new major versions of PostgreSQL.

Source code tarballs are built automatically every night on the official
PostgreSQL development server. The
[development snapshot](https://www.postgresql.org/ftp/snapshot/dev/) is taken from the
head of the git repository, and includes the new features being worked
on for the next release. There are also "branch tip" snapshots built from
all supported [stable branches](https://www.postgresql.org/ftp/snapshot/), which contains
all bugfixes that are scheduled for the next release.

RPMs for Red Hat, Rocky Linux, AlmaLinux and, Fedora are available from the
[PostgreSQL Yum repository](https://yum.postgresql.org/).

To setup the repository for these versions, follow the same instructions
as for the [normal](https://www.postgresql.org/download/linux/redhat/) yum repository on these
platforms.

DEBs for Debian and Ubuntu are available from the
[PostgreSQL APT Repository](https://apt.postgresql.org)
repository.

To setup the repository for these distributions, follow the instructions
on [Linux Downloads (Debian)](https://www.postgresql.org/download/linux/debian/) or [Linux Downloads (Ubuntu)](https://www.postgresql.org/download/linux/ubuntu/).

Installers for Windows and Mac are available 
[here](https://www.enterprisedb.com/products-services-training/pgdevdownload) (offsite link). These installers also include pgAdmin and are
published by EDB.

Only Beta and Release Candidate packages are available as installers.
