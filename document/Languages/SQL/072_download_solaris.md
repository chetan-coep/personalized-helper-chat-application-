# SQL

Source: https://www.postgresql.org/download/solaris

---

The PostgreSQL community currently does not provide binary packages for Solaris.

PostgreSQL can still be built from source and used on Solaris. Please see
[the PostgreSQL buildfarm status](https://buildfarm.postgresql.org/cgi-bin/show_status.pl)
for information about which combinations of versions and compilers are actively being tested.
